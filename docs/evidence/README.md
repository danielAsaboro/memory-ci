# Production evidence receipts

`stash-production.json` is generated only after authenticated production checks succeed. It is safe to commit only when generated by the script: the generator redacts account IDs, email addresses, credentials, tokens, and credential-bearing URLs. Keep interim smoke and vector receipts outside this directory (for example, under `/tmp`).

Receipts use schema version 2 and are strict, kind-specific documents: `aws-smoke`, `vector`, and `ccloud`. Each must carry the same fresh run ID, AWS account/region/stack/API/bucket/event-bus/model/secret-ARN context and CockroachDB organization/cluster/provider/region/tier/host context. The final collector independently verifies STS and CloudFormation identity, exact structured CloudWatch request/run/trace records, and the exact X-Ray root. It will not accept a context-only envelope, fixture, local target, unrelated recent log, or unrelated trace.

The generator refuses local databases, fixtures, incomplete stack states, missing provider request IDs, or missing health, idempotent workspace persistence, Bedrock evaluator and 1024-dimensional embedding, versioned S3, EventBridge, CloudWatch, X-Ray, and exact CockroachDB vector-index evidence. Interim receipts are written atomically only after their producer checks pass.

After authentication, run the commands in the task report. Do not hand-author a success receipt or substitute a local result for a production probe.
